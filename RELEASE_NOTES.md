## Orbi 0.1.27-4

**Fixes**
- Updates now show a small progress window ("Installing Orbi…") and Orbi reopens by itself when it finishes. Before, the install ran invisibly, so opening Orbi during it showed "file in use".
- Opening Orbi while it is already open now brings up the existing window instead of starting a second copy.
- FLUX.2 klein 4B downloads again (the model repository uses different file names).
- More robust model downloads when a repository renames its files.

Developed by Daniel Rodrigues.
