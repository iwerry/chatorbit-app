## Orbi 0.1.27-2

**New**
- Setup assistant on first launch: language, theme, and the best local AI for *your* PC (chat, images, video, voice).
- Stronger models matched to each machine: Qwen3 4B/8B, Gemma 3, FLUX.2 klein 4B, Z-Image Turbo, Wan 2.1 on 4 GB GPUs.
- Search Hugging Face and install any compatible model.
- Workflows that really run: connect nodes (prompt → text AI → image → video → board), run one node or the whole graph.
- Automatic updates: Orbi tells you when a new version is out and installs it when you want.
- Your theme (Light, Dark, Terminal) is remembered.

**Fixes**
- Local chat no longer runs out of context with web search on.
- Local models use the GPU automatically and safely.
- Replaced an image model the engine could not load; clearer error messages.

Developed by Daniel Rodrigues.
